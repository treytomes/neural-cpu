## Key Design Decisions

**Event Bus as Central Nervous System**: Rather than direct component coupling, all communication flows through the event bus. This enables the future neural control plane to observe and participate in the same message flow.

**Records for Immutability**: Event messages are immutable records with primary constructors, providing structural equality and thread-safety guarantees essential for concurrent event processing.

**Observable Determinism**: Every component action is an observable event. This makes the system's behavior completely traceable and will allow the neural network to learn from observation.

## Insights & Observations

The architecture feels clean and extensible. The event bus abstraction successfully decouples components while maintaining the CPU metaphor. The two-phase clock provides enough granularity for realistic component behavior.

Using records dramatically reduced boilerplate (50%+ reduction in event class size) while adding immutability guarantees we need for thread-safe event processing.
